# Agent guidance

Read [.github/copilot-instructions.md](.github/copilot-instructions.md) for the shared
rules and [README.md](README.md) for the available agents and skills.

This is an independent, lightweight template for Azure DevOps and Salesforce analysis.
The repository root is also the SFDX project root; `force-app/` holds metadata for review.
Keep reusable guidance here; teams add their own domain instructions and workflows.
The checked-in host configuration targets GitHub Copilot in VS Code. Other clients
need their own MCP configuration and agent/tool mapping.
